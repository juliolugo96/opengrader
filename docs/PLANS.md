# OpenGrader Editions and Plans

OpenGrader uses the same open assignment and result formats in every edition.
An instructor can begin locally, move to hosted operation, and return to local
operation without converting assignments or grade exports.

## Community — Free

For individual instructors, open-source users, and teams operating their own
infrastructure.

- Local CLI and grading engine
- Docker runner
- Parallel batch grading
- Partial credit and retries
- JSON, Markdown, and CSV reports
- Authenticated API
- Operations dashboard
- PDF rubric grading and feedback export
- Community documentation
- Open formats
- Self-managed infrastructure

## Hosted — Early access, usage based

For programs that want OpenGrader without operating the full service.

- Hosted subscription access
- Automated and PDF grading operations
- Stripe Checkout and subscription management
- Durable usage metering
- Usage and delivery dashboard
- Open result exports
- Upgrade or return to local operation without format lock-in

Planned hosted-service enhancements:

- Managed autoscaling workers
- Hosted backups
- Extended analytics
- Operational support

## Institution — Custom

For universities, bootcamps, and enterprise learning organizations with
identity, policy, support, and integration requirements.

Available now:

- Canvas assignment import
- Canvas grade synchronization

Roadmap and design-partner capabilities:

- Role-based access (planned)
- SSO (planned)
- Long-term audit retention (planned)
- Broader LMS integration packages (planned)
- Additional LMS adapters (planned)
- Hosted result retention and backups (planned)
- Policy-controlled worker infrastructure (planned)
- Service-level commitments (planned)
- Enterprise deployment tooling (planned)
- Priority support (planned)

Canvas grade synchronization is implemented while retaining the
provider-neutral adapter boundary for future LMS integrations.
